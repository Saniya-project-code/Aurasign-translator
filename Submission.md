## Project Title
AuraSign Translator

## Project Description
AuraSign Translator is an AI-powered web application that translates sign language gestures into text and speech in real time. Built using MediaPipe Hands and TensorFlow.js, the platform detects hand landmarks, processes gesture patterns, and provides instant communication support for users. The project aims to bridge communication barriers and improve accessibility for the deaf and hard-of-hearing community.
